# Project Atlas

**Company:** Froto  
**Founder:** David Yardley  
**Document series:** Project Atlas  
**Status:** Active  
**Version:** 1.0

Project Atlas is the living strategic foundation for Froto. It connects the company's purpose, product strategy, customer needs, roadmap, architecture, and major decisions in one version-controlled knowledge base.

## Purpose

Project Atlas exists to ensure that Froto is built deliberately. Every major product, commercial, and technical decision should be traceable back to a documented customer need, product principle, or company objective.

## Working Rule

Nothing is considered final unless Froto would be prepared to defend it in front of a customer, investor, partner, employee, or future board.

The files in this directory are the primary source of truth for Project Atlas. Presentation versions may later be exported to Word or PDF, but changes should first be recorded here.
